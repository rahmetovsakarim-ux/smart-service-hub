## Толық сипатталған Use Case-тер

Төменде негізгі төрт Use Case толық сипатталды.

| **Use Case: UC-05 «Тапсырыс қалыптастыру»** |
| --- |
| **Actor** | Клиент (қосымша: Smart Service Hub жүйесі, SMS/Push провайдері) |
| **Бастапқы шарт** | Клиент жүйеге кірген (UC-02). |
| **Негізгі сценарий** | 1. Клиент каталогтан (немесе дауыспен іздеу арқылы) қызметті таңдайды. 2. Жүйе қызмет туралы ақпаратты (сипаттама, баға) көрсетеді. 3. Клиент тапсырыс формасын толтырады: мекенжай және қызмет көрсету уақыты. 4. Жүйе енгізілген деректерді тексереді. 5. Жүйе тапсырысты дерекқорға тіркейді (статус = New). 6. Жүйе бос және жақын маманды автоматты іздеп, тағайындайды (UC-15). 7. Жүйе маманға SMS/Push хабарлама жібереді (UC-14). 8. Жүйе клиентке тапсырыс нөмірі мен статусын көрсетеді. |
| **Балама сценарий** | 4а. Деректер толық емес немесе қате болса, жүйе қате туралы хабарлама көрсетіп, 3-қадамға қайтарады. 6а. Маман табылмаса, жүйе Әкімшіге escalation-хабарлама жібереді; Әкімші маманды қолмен тағайындайды (UC-11). |
| **Нәтиже** | Тапсырыс жүйеде тіркеледі (статус = New); маман тағайындалады немесе тағайындау Әкімшіге беріледі. |
| **Байланысты талаптар** | FR-05, FR-06, FR-08, FR-09, FR-14; US-03 |

| **Use Case: UC-09 «Тапсырысты қабылдау / бас тарту»** |
| --- |
| **Actor** | Маман |
| **Бастапқы шарт** | Маманға тапсырыс тағайындалған; маман жүйеге кірген. |
| **Негізгі сценарий** | 1. Маман өзінің тапсырыстар тізімін ашады. 2. Жүйе тағайындалған тапсырыстарды (қызмет, мекенжай, уақыт) көрсетеді. 3. Маман тапсырысты таңдап, мәліметтерін қарайды. 4. Маман «Қабылдау» әрекетін таңдайды. 5. Жүйе тапсырыс статусын Accepted күйіне ауыстырады. 6. Жүйе клиентке хабарлама жібереді (UC-14). |
| **Балама сценарий** | 4а. Маман «Бас тарту» әрекетін таңдаса, жүйе Әкімшіге хабарлама жібереді, Әкімші басқа маманды тағайындайды (UC-11). |
| **Нәтиже** | Тапсырыс Accepted статусына өтеді, клиент хабардар болады. |
| **Байланысты талаптар** | FR-07, FR-08, FR-09, FR-14; US-06 |

| **Use Case: UC-10 «Орындау статусын жаңарту»** |
| --- |
| **Actor** | Маман |
| **Бастапқы шарт** | Тапсырыс статусы Accepted; маман жүйеге кірген. |
| **Негізгі сценарий** | 1. Маман жұмысты бастағанда тапсырысты «Орындалуда» деп белгілейді. 2. Жүйе статус тізбегін тексеріп, статусты In Progress күйіне ауыстырады. 3. Жүйе клиентке хабарлама жібереді (UC-14). 4. Жұмыс аяқталған соң маман тапсырысты «Аяқталды» деп белгілейді. 5. Жүйе статусты Completed күйіне ауыстырып, өзгерісті журналға жазады. 6. Жүйе клиентке хабарлама жібереді; клиентке төлем жасау және бағалау мүмкіндігі ашылады. |
| **Балама сценарий** | 2а. Статус тізбегі бұзылса (мысалы, Accepted күйінен бірден Completed күйіне), жүйе қате туралы хабарлама көрсетіп, өзгертуге жол бермейді. |
| **Нәтиже** | Тапсырыс Completed статусына жетеді; өзгеріс тарихы сақталады. |
| **Байланысты талаптар** | FR-08, FR-09, FR-15; US-07 |

| **Use Case: UC-08 «Қызметті бағалау»** |
| --- |
| **Actor** | Клиент |
| **Бастапқы шарт** | Тапсырыс статусы Completed; клиент жүйеге кірген. |
| **Негізгі сценарий** | 1. Клиент орындалған тапсырысты ашады. 2. Жүйе бағалау формасын көрсетеді. 3. Клиент баға (1–5) мен пікір енгізеді. 4. Жүйе бағаны тексеріп, сақтайды. 5. Жүйе маманның орташа рейтингін қайта есептейді. 6. Жүйе бағаның қабылданғаны туралы растау көрсетеді. |
| **Балама сценарий** | 4а. Тапсырыс Completed емес немесе баға бұрын қойылған болса, жүйе бағалауға жол бермейді. |
| **Нәтиже** | Баға мен пікір сақталады, маман рейтингі жаңарады. |
| **Байланысты талаптар** | FR-10; US-05 |
